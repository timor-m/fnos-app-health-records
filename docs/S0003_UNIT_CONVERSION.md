# S0003 甲状腺指标单位转换

## 已确认的问题

工单建议不同医院的可换算单位汇总到同一趋势，先后补充了总甲状腺素 nmol/L 与 μg/dL，以及游离三碘甲状腺原氨酸（FT3）pg/mL 与 pmol/L。两份附件均为应用趋势截图，没有报告原件。核心字典已允许这些单位，但 convertUnit 缺少对应项目的质量/摩尔浓度换算，因此保留原单位并拆成不同趋势。单独安装字典更新无法修复。

## 最小修复

在既有 convertUnit 内按指标增加双向换算，依据 [Mayo Clinic Laboratories SI 单位换算表](https://www.mayocliniclabs.com/order-tests/si-unit-conversion.html)：

- 总 T4：μg/dL → nmol/L 乘 12.87，反向除 12.87。
- 游离 T3：pg/mL → pmol/L 乘 1.54，反向除 1.54。沿用该表公布的换算精度。

保留总 T4 的 μg/dL、ug/dL、mcg/dL 规范化；FT3 复用现有单位规范化。因子限定具体指标，不套用到总 T3、游离 T4 或其他物质。

复用既有数值、参考范围及字典参考范围换算路径，保留限值符号和原件字段，不重写原结果、原单位或原报告参考范围。其他无法可靠换算的单位继续分图，不增加用户公式、通用换算引擎或前端配置。

前次总 T4 修复将标准化规则从 p16 改为 p17；新增 FT3 后改为 p18，使已有派生匹配记录通过既有后台回填重新计算。沿用趋势快照失效机制，无需重新 OCR 或调用 AI。应用版本、数据库结构和远程字典均未修改。

## 验证边界

使用合成报告记录验证双向换算、单位大小写与微符号、负向边界、趋势合并、参考范围、限值结果、历史回填及原值保留。总 T4 与 FT3 共享同一组数据流程用例，既有游离 T4 不支持换算时继续分图。无用户报告原件，没有将应用截图作为报告上传，不声称完成原报告重跑或原设备验证。
