# S0003 总甲状腺素单位转换

## 已确认的问题

工单最初建议不同医院的可换算单位汇总到同一趋势，后补充了明确案例：总甲状腺素 nmol/L 与 μg/dL。没有报告附件或检查结果。核心字典早已允许这两种单位，但 convertUnit 缺少该项目的质量/摩尔浓度换算；已有逻辑因此保留原单位，将记录拆成不同趋势。这是应用换算能力缺口，单独安装字典更新无法修复。

## 最小修复

在既有 convertUnit 内，仅为 thyroid_t4_total 增加 μg/dL → nmol/L（乘 12.87）及反向换算（除 12.87）。依据 [Mayo Clinic Laboratories 的 SI 单位换算表](https://www.mayocliniclabs.com/order-tests/si-unit-conversion.html)，总 T4 的 mcg/dL 转 nmol/L 因子为 12.87。补充 μg/dL、ug/dL、mcg/dL 的大小写规范化；不新增通用质量/摩尔换算公式，不将相同单位的因子套用于游离 T4、总 T3 或其他物质。

复用既有数值、参考范围及字典参考范围换算路径，保留限值符号和原件字段；不重写原结果、原单位或原报告参考范围。无法可靠换算的其他单位仍保留分图，不新增用户公式或扩大医学范围判定。

标准化规则版本从 p16 改为 p17，使已有派生匹配记录通过既有后台回填重新计算；沿用趋势快照失效机制，无需重新 OCR 或调用 AI。应用版本、数据库结构和远程字典均未修改。

## 验证边界

使用合成报告记录复现不同单位的趋势及原始/派生字段。验证双向换算、ASCII/微符号单位、负向边界、参考范围、限值结果、历史回填与原值保留；既有游离 T4 不支持换算时继续分图。没有用户报告原件，不声称重跑了原报告或覆盖原设备。
