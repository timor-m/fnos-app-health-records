# 报告重复检测（family-v2，未发布）

判断对象是同一成员下“同一份报告的同一个结果版本”。同医院、同一天、同门诊号或通用正常结论均不能独立证明重复。自动判断不删除、合并或隐藏结果；只有完整原件一致或仍适用的人工确认沿用现有趋势折叠语义，不做相似关系的传递推理。

## 两阶段和证据

1. 完整本地任务完成后进行原件/OCR 前置评估。候选召回、证据分类和暂停动作分别处理，`confidence=high` 仅保留为兼容展示字段。
2. 整份 AI 计划持久化、标准化、任务完成后进行本地后置核验；补页在最终内容发布后核验。无需新增模型调用。后置结果不撤回已生成的解析结果，核验自身失败记录独立状态，可以在详情重试。

`report-duplicate-evidence.ts` 是无数据库、无网络的报告对评估器；`report-duplicate-snapshot.service.ts` 复用现有 OCR 行重建、候选及字典，并从当前 AI 结果读取结构化字段。每项事实保留页码、行引用、原文及质量。AI 结构化项替换同一范围的 OCR 项，不能重复加票；未解析候选仍进入分母。重复测量按多重集合一对一消耗，不按名称 Set 去重。

事实状态包括 exact、equivalent、compatible、uncertain、conflict、missing。OCR 行置信度缺失不视为可靠；初始可靠阈值 0.90，只用于来源质量分层，不代表重复准确率。弱行的差异可以成为 uncertain；可靠行的一处真实变化不能因其他项相同被降级。数字使用字符串规范化：5.10 等价于 5.1，5.18 不等价于 5.19；比较符号、定性等级、单位、参考范围及异常标志保留。仅实现明确的 g/L ↔ mg/L 十进制移位，不猜测跨分析物换算。

报告编号需要机构及具体检查范围；门诊号、住院号和患者号不参与强身份。保留编号前导零及分隔符，同一报告内的多个编号不覆盖。采样、检查、报告签发及打印时间分开读取；分钟/秒可相容，日期不能用于无编号强事件分支，打印时间不作为冲突。

## 初始参数

| 规则 | 要求 | 可否前置暂停 |
| --- | --- | --- |
| R0 | 完整原件 sha256 + PDF 选页身份的多重集合一致；忽略文件名、顺序；保留重复页数量，拒绝尚未展开的 PDF 占位页 | 可以 |
| R1 | 同机构、强报告编号、相同具体范围；双向可靠匹配覆盖 ≥90%；未知数 ≤min(2, floor(N×10%))；可靠锚点 ≥4；零可靠结果冲突、零重大完整性风险 | 可以 |
| R1.short | 1–3 项：强报告身份、精确到分钟的同类事件、全部可靠对应、无未知 | 可以 |
| R1 无时间 | 在一般门槛之上至少 10 个锚点，并有相同标本/检查/条码辅助编号；只有日期但内容充分可走一般 R1 | 可以 |
| R2 | 同机构、相同范围、精确同次采样/检查事件；双向覆盖 ≥95%；未知 ≤1 且 ≤5%；可靠相同 ≥10、锚点 ≥6；零冲突及重大风险 | 可以 |
| R3.results | 双方已有当前 AI 结果；身份或强事件 + 实际内容；双向覆盖 ≥80%、可靠相同 ≥3、未知 ≤20%；无可靠冲突/单侧新增/重大风险 | 只提示 |
| R3.narrative | 身份或强事件 + 范围；完整所见/结论及结构化章节相同，有原文支持，至少 60 字，未遗漏其他长叙事事实 | 只提示 |
| R4 | 同编号但可靠内容变化或新增内容：related_variant；明确不同报告号/同类事件：different | 不暂停 |

N 包含完整候选范围中的未解析项。两个未知项目不能从分母消失。整页 OCR 缺失/空白/低质、修订备注、内容预算截断和未覆盖叙事阻止内容暂停。页数不同本身不一票否决：完整事实覆盖可证明同一内容；子集/新增项目不能作为完整重复。

## 暂停、继续与并发

只有 R0/R1/R2 达标且目标具有对应当前原件的有效 AI 提取、已保存结果、可用来源证据，才可能暂停。目标仍在处理、补页、回收站或已有 distinct 都不能作为暂停理由。仅 `ready` 或一条 observation 不够；结果型目标还要求至少 80% 的完整候选范围有可靠结果证据。两份同时上传、都没有有效结果时均不相互暂停。

暂停写入 `report_duplicate_runtime`，包含双方证据版本、规则、目标、原因、源版本和批次键。同步短事务内复核目标，事务不等待网络。证据版本覆盖原件、OCR 内容/版本、AI 提取、人工覆盖、字典版本及规则版本；不依赖 `updated_at`。重复事件绑定证据键。目标失效时详情显示“原先暂停已失效”；重新聚焦详情会刷新。

- **仍然继续整理**：只记录当前原件版本的显式继续，不写任何 distinct。
- **不是重复并继续整理**：只保存当前暂停目标这一对的 distinct，继续当前报告；不会修改其他候选。
- 相同继续请求复用活动或已记录的任务；失败任务通过现有重试流程处理。普通显式重新整理仍可启动新批次。
- 继续前检查成员管理权限、AI 配置、本地任务状态和完整 OCR 输入。只读账号可查看获授权的报告和对比，不能修改。
- 确认、排除、撤销继续使用现有治理记录。人工 duplicate 绑定原件签名，原件变化后历史仍保留，但旧决定不继续折叠新内容；distinct 不因 OCR/AI 重跑而删除。

## 召回、预算与可观测性

普通候选默认最近 80 份，现有设置扫描仍限制来源 300 份及返回候选数量。另用同成员原件哈希、报告级编号、精确事件检索补充历史候选，不受最近 80 份限制；不进行全库两两比较。普通扫描复用请求内快照，避免逐对反复解析 OCR。单次候选最多 600，单个强检索分支最多 301，编号最多 8 个；返回检索窗口/截断信息，不声称覆盖全部历史。

正文输入预算 200,000 字符（含 OCR JSON），项目上限 2,000。截断不能用于完整一致证明。详情 `duplicateSearch` 区分无候选、存在但不足、匹配及窗口限制；`duplicateVerification` 区分后置完成、失效、失败。GET 不触发 AI，不保存人工决定。

## 历史恢复和兼容

应用仍为 0.2.10，schema 仍为 v17。新增未编号 `report-duplicate-draft.ts`，新库与旧库均创建运行状态表和原件检索索引；旧库启动补齐前自动备份，不清库、不改已发布迁移、不自动入队。

旧 family-v1 的机器 high 不沿用。设置 → 重复报告检测 → 开始检测，会显示尚未由当前规则复核、有明确旧 `duplicate_precheck` 历史、尚无有效 AI 提取且没有活动/失败本地任务的恢复数量。管理者点击“重新检查并继续整理”，按新规则重新判断；仍充分重复的保留暂停，其余按现有 AI 配置入队。单批最多 100；已复核且仍暂停的转入当前规则处理，不占用后续旧记录的恢复批次，可从报告详情显式继续。没有事件证据的 needs_review 不臆测为历史误判。

旧库没有源签名绑定的 AI 结果不猜测其是否对应当前原件，因此不会单凭历史完成状态阻止新报告。正常完成一次当前版本整理后即建立绑定。旧人工确认及审计记录保留；缺少原件绑定的历史 duplicate 会显示待复核说明，可在治理历史点击“重新确认当前原件”，重新核对后才能继续用于内容折叠，完整原件相同的关系仍保留。distinct 始终优先。

## 评测与风险

运行 `npm run duplicates:evaluate`：使用临时库、纯合成 OCR/提取结果，退出清理；不接触真实数据库，不调用 OCR/AI 网络。标签由“同一来源的变体”或“独立事件/结果变化”的生成方式确定，校准/验证使用独立编号、成员及数值族。脚本实测候选召回、前置正确/错误暂停、误拦占比、后置增益、不足数量、比较数及耗时，并按类别输出。历史超过窗口的召回和 1,200 份规模约束另由服务测试验证。

当前每组 12 个样本（8 个真实重复、4 个复查/缺页/新增/差异）：候选召回 8/8，前置正确暂停 5/8，错误暂停 0，后置额外检出 2/8，总检出 7/8，1 个信息不足的短报告放行；24 次阶段比较。该小型合成集只能作为回归和边界验证，不能外推真实准确率。

首版保守限制：机构名称不做模糊等价推断；OCR 缺质量、复杂跨行表格、未可靠重建的病理/处方/住院版式、科学计数法及未配置单位转换可能放行到 AI 或维持不足。叙事适配要求完整原文支持，不用摘要前缀猜测。历史 AI 缺少源绑定时优先保证不误拦，会增加一次正常整理的机会。需要继续用经授权的脱敏人工标注样本验证召回、解析质量及交互。

原文、数值和编号仅留在获授权的本地证据/对比层；审计运行日志和变更说明不写这些内容。不增加外部判重服务、模型调用、遥测或健康数据上报。
