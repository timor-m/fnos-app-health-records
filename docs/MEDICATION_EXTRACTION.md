# 用药识别适配说明

## 分类与路由

文档分类与用药内容分别判断。门诊病历、出院小结和综合体检保留原文档类型；页面存在明确用药标题，或药品与用法、规格数量表格等组合证据时，标记为包含用药内容。识别不依赖医院名称或固定模板。

概览和详细模式都通过现有 `narrative` 路由提取用药，输出 `medications`；不新增数据库类型或迁移。概览只选择有用药证据的页面，详细模式仍保留其他叙事内容。混合文档不因用药只是次要类型而丢失药品输出契约。单元拆分重试保留用药标记。

## 成员归属核对

用药单沿用报告的本地身份核对，不依赖 AI 重跑。识别明确的姓名、患者姓名、用药人等标签及相邻 OCR 值；不将无标签人名或医生、药师姓名当作用药人。每页只读取最新 OCR。

成员没有性别、生日也会进行姓名核对；姓名与成员称呼不同时请求确认，不能直接认定选错成员。姓名未可靠识别、现有患者信息又缺少可比对的成员资料时，显示“成员归属待核对”，不声明身份冲突。可确认属于当前成员、选择已有成员或创建成员归属；确认提醒不自动改动成员资料，重新归属后重新评估。

成员核对回归覆盖姓名独立信号、标签分行/空格、医师及联系人排除、资料缺失、确认提醒和最新 OCR 选择。分别移除姓名提醒、资料不足提醒、最新 OCR 选择后，对应回归失败；既有报告 OCR 也验证了资料不足提示分支。此验证不需要重新 OCR 或调用 AI。

## 场景与版式矩阵

| 场景或版式 | 分类依据 | 提取规则 |
| --- | --- | --- |
| 处方标题含空格、编号列表 | 处方标题或药品与用法组合 | 保留编号、药名及后续用法 |
| 无标题药品表 | 药品名称、规格、数量表头 | 允许提取明确规格数量，不推断剂量或频次 |
| 药名与用法分行 | 药品剂型与用法组合 | 只按明确连续上下文归属 |
| 门诊病历内用药表 | 病历标题及用药证据 | 保留门诊分类，按章节填写用药 context |
| 出院带药、出院用药表 | 出院文书及用药章节 | context 使用 discharge |
| 临时/长期医嘱 | 明确医嘱标题 | 即刻、必要时和频次缩写按原文保留 |
| 左右多栏表格 | OCR 保留的表头和列关系 | 每组药名与本组用法配对，不跨栏拼接 |
| 多页清单，无重复标题 | 前页用药证据及相邻页药品规格/用法 | 保留连续页；不跨缺失页推断 |
| 药名与用法跨页 | 相邻页连续上下文 | 分别保存来源页证据，归属不明的字段留空 |
| 体检中明确的当前用药 | 体检主类型及用药章节 | 保留体检分类，同时允许输出用药 |

续页规则会在无用药证据、页码不连续，或切换为检验、票据等内容时停止。不能依靠相邻关系把收费表或过敏史变成用药。

## 字段及误识别边界

- 药品名称、盐型、规格和剂型保留原文，不凭商品名猜通用名。
- 规格、每次剂量、数量、疗程分别提取，缺失字段不推算。
- 停用、暂停、调整和既往用药说明保留在 `instructions`，不得改写成当前服用；当前结构没有独立用药状态字段。
- 同名条目若剂量单位、频次、途径、疗程、数量或说明不同，不因名字相同而合并。
- 单纯收费明细、药品说明书、过敏史及泛泛的健康建议不作为用药事实。
- 临床事实继续通过 OCR 原文证据校验后入库，人工修改和删除保护沿用原流程。

## 验证及限制

合成夹具位于 `packages/server/tests/fixtures/medication-layouts.ts`，不含真实患者或报告内容。测试覆盖上述 10 类场景、5 类反例，以及概览/详细两种模式的规划、跨页标记、请求契约、证据与持久化。模型响应由测试模拟；这些测试证明分类与数据链路能够承载相应内容，不证明真实模型对每种排版都能正确识别。

多栏支持依赖 OCR 保留可辨认的列关系；照片倾斜、药名模糊、手写内容和版面已被 OCR 错拼时，仍需核对。跨页条目若因请求预算或重试被分到不同单元，不强行补全缺失用法。药品字段目前没有逐字段的剂量核验机制，不能把原文匹配当作全部用法已自动核实，也不生成用药建议。

本次未执行真实 AI、原图 OCR 或 fnOS/Docker 安装验证。部署后可用授权的测试材料重新整理，核对药品数量、规格、剂量、频次、途径及来源页。旧报告不会自动重跑，不改原件和人工校对记录。
