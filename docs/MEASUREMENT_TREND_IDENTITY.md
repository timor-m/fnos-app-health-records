# 测量趋势身份

0.3.4 未发布。测量身份构建由 `packages/shared/measurement-trend-identity.ts` 统一处理；指标在 `packages/shared/measurement-indicators.ts` 声明需要的维度。定义随应用代码发布，本轮不改变远程字典格式、已安装字典快照或数据库结构。

## 维度声明

可声明 `measurementSite`（部位）、`measurementLaterality`（侧别）、`examinationModality`（检查方式）、`method`（具体测量方法）。标准指标键始终作为身份第一部分，单位仍由既有趋势单位规则区分。未声明的维度不参与身份，不改变普通检验指标的既有口径。

例如一个新测量定义可以只声明：

```ts
example_measurement: {
  dimensions: ['measurementSite', 'measurementLaterality', 'examinationModality', 'method']
}
```

新增定义不应修改已发布指标的维度或兼容编码；确需调整时，必须单独核对历史趋势与关注关系。

主趋势计算无需再添加 `if CT` 或按科室套用不同构建函数。声明顺序不影响身份，方法中的大小写、空白统一；分隔符转义，避免名称中的 `@`、`%` 破坏解析。缺失值保持缺失，不根据数值推断部位、侧别或方法。AI/OCR/manual 仍是来源渠道，不当作具体测量方法。

这不表示只添加名称就完成一种检查接入：新项目的医学语义、单位、字典及原件解析仍须核实；新增部位的输入选项和专项展示另按实际需求接入。本轮不实现 DICOM 或通用动态表单。

## 旧身份兼容

- 现有 DXA 的 `指标@部位@侧别` 继续原样保留。DXA 项目本身已经限定方式，旧 `method=DXA` 在身份编码中作为方式处理，不伪装成具体测量方法，也不回填观察项字段。
- 现有心脏的 `指标@cardiac@部位@方式@方法` 编码继续保留；缺少部位和独立方式的旧记录保留原指标键，即使旧 method 有文字也不改变其关注键。
- 左右侧髋关节中轴长度仍分别保留原指标键；原 DXA 默认口径不改键，明确不同方式或具体方法时才拆分，继续作为独立长度项而非 BMD/T/Z 页签。
- 新项目不需要旧编码配置，使用共用维度编码。DXA 如明确出现额外方法或不同方式，也使用完整上下文编码，避免混入旧部位卡片。
- 旧编码适配只用于保留已有身份，不用于新检查设计，不批量改写数据或关注记录。

## 专项行为保留

骨密度、心脏的解析器、来源和医学口径准入不搬入通用身份引擎。原先的公开构建函数保留为薄适配入口，供已有 UI 和调用方使用，不再各自实现组合与转义。

骨密度继续使用 BMD/T/Z 页签；同一完整上下文才能归入一张卡片及一组关注，方法不同的卡片分别分页和计数。心脏继续保留方法未明确时不默认比较，以及“右室常规”的原始项目待核对提示。分组通过共用解析器取标准指标键，兼容旧键和新编码。

原有骨密度表单继续使用，编辑既有方法时不强制覆盖成 DXA；只有明确 DXA 方式或原 method=DXA 的骨密度才满足原方式校验，不能因此把 CT 数值收进 DXA 标准项目。专项医学判断与身份拆分是两件独立的事。

## 验证

使用合成数据覆盖旧键逐字节兼容、新 CT 定义不增加主流程分支、四维隔离、未声明维度不影响身份、方法大小写/分隔符、未知和损坏键、骨密度页签/关注/分页、旧客户端编辑与旧关注。原件仅做本地只读比对，不重新识别、不新增 AI 调用。

完成后消融维度参与及旧编码兼容，确认回归能检出误合并或键变化，再恢复实现。只保留声明表、共用构建/解析及必要兼容适配，不新增规则执行器、动态插件或事件层。


## 展示卡片与数据序列

`trend-card.ts` 只定义展示身份：已声明的普通测量按指标、部位、侧别、单位成卡，方式和方法作为卡内切换项。来源趋势身份不变，图表与历史仍用原序列键读取，未知部位不推断，原始项目及普通检验保持独立。骨密度保留同完整口径的 BMD/T/Z 专项卡片与关注范围。

查询在连接上注册同一纯函数，用于卡片计数、分页、关注和分组统计；不增加数据库字段或重写旧关注。分页按匹配卡片返回其匹配口径，搜索与状态筛选不带入不匹配的数据。旧的任一口径关注视为整卡关注，取消时只删除同卡的关注。选择项拆成检查方式、测量方法两行，沿用骨密度切换按钮样式；方式或当前方式下的方法只有一个选项时隐藏对应切换行；方法只列当前方式已有项，切换方式优先保留同名方法，否则选其已有方法。触屏使用紧凑按钮和行间距，自动换行、长文案可折行；切换只改变当前显示的序列，不重新提取报告。

回归覆盖同指标四种方式/方法、不同与缺失部位、单位隔离、整卡关注及取消、切换中关注防重复、搜索与单卡分页。消融展示归并及选择状态后，对应回归均检出拆卡或切换失效；恢复后通过完整服务端、界面测试、类型检查及构建。本地模拟卡片和既有超声、双侧骨密度记录均通过只读比对，未重新提取或修改原件。

两行按钮回归包含稀疏组合和未注明口径：方法仅随当前方式展示；跨方式优先保留同名方法，无此方法时回退到已有序列。消融方法范围约束后回归检出无效方法选项，恢复后通过；不增加独立的方式/方法状态，继续只保存所选原序列键。
