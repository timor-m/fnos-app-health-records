# OCR 表格提取

## 当前实现

- 同类问题共用修复：数字仅清理全角和明确小数点周围空格，不反转数字；前置异常箭头与数值分离解析。明确表格按本次结果列校正返回值，不再借用名称后一格；缺单位仅从同表单位列或 `结果(U/L)` 等明确表头恢复，不覆盖已有冲突单位。有非空结果但漏提的安全行复用既有有界补提取，不另建重试循环。`9/L` 等可疑原文不自动替换字符。
- 提取层不按参考范围猜测小数、不按指标名称补缺失单位、不用分类百分比之和生成缺失项，也不因单项数值极端直接删除。疑似乱码保留结果原文、不生成可靠数值，继续走既有核对与证据准入。带明确上下文的肺功能、人体成分等版式解析仍保留。
- 保留现有 OCR 原文、页码、坐标、单元格来源和表头来源，不覆盖原始证据。
- 表头中的“异常”是合法列名，不作为结果行排除。
- 本地提取和 AI 证据校验共用本次结果列规则，排除历史、预测及参考列。
- AI 证据校验保留空单元格；明确分格但列数不一致或结果为空时，不猜测其他列为结果。本地专用肺功能等布局解析仍保留已有适配。
- 无分格的纯文本继续使用原有行内解析；多组并排结果不允许通过整行任意值匹配。
- 拒绝仅影响对应指标，其他已验证结果继续保留。界面不再暗示所有候选均已执行补提取。

## 安装与旧版升级

- fnOS：优先从应用中心更新应用，再由管理员进入“运行与识别”，点击“升级 OCR · 表格增强”。
- Docker：更新镜像并保留 `/data`，在同一入口升级。当前镜像仍采用按需安装 OCR，不是镜像内置 Python 依赖。
- 首次安装先安装基础 OCR，再安装表格组件；旧基础 OCR 自检通过时不重装、不删除其就绪标记。
- 表格依赖独立安装到 `STORAGE_DIR/ocr-table/runtime-*`，固定 RapidTable 3.0.2、RapidLayout 1.2.1、ONNXRuntime 1.19.2，不改原 OpenVINO / ONNX 环境。
- 依赖、模型下载及推理自检成功后，原子更新 `ocr-table/active.json`。新推理读取新指针，已启动的推理使用原环境；失败保留原指针和旧 OCR。
- pip 沿用运行页镜像源；模型从 ModelScope 下载，pip 镜像源不代理模型下载。安装失败可重试；同版本模型摘要检查通过时不重复安装。
- 旧环境与失败目录暂不自动清理，避免删除使用中的环境。进程意外终止遗留 `.install-lock` 时，确认无安装进程后只删除该锁目录，勿删除数据目录。

## 结构增强与回退

RapidLayout 定位表格，RapidTable 只提供单元格几何与行列关系，文字仍取自原始 OCR。元数据随原有 OCR JSON 保存，不新增 migration。

预处理按逻辑列恢复空单元格；空格没有虚构文字或证据 ID。合并单元格、归属冲突或结构缺列仅使涉及的行待核对，不丢弃整表其他完整行；歧义行禁止本地按压缩列序号生成指标，也不能通过 AI 证据校验。当前不自动展开跨行跨列结构。

当模型标记的不安全文本多于已映射文本时，预处理可对单一、明确表头进行坐标恢复：名称与本次结果须同排且唯一，不能跨结果列或借用参考值；缺结果、多结果及并排表头仍待核对。参考范围和方法续行仅保留在附属列，不连带拒绝已核验的结果。有效的模型网格保持不变，原始 OCR 文本和坐标不覆盖。

恢复行中的单位若与明确的比较符参考限值粘连，仅在参考列为空且单位形态明确时拆分，两个单元格共用原始 OCR 引用；不按任意数字切分。恢复结果直接复用现有 AI 输入、证据校验和趋势准入，不新增接口、模型或数据库结构。

OCR 首行可携带 `tableDiagnostics`，仅记录增强状态及采纳/歧义文字框数量，不含健康正文；可区分未安装、关闭、推理失败、无可用结构、部分采纳和完整采纳。修复脚本后需重启应用以重新加载常驻 OCR worker，无需重新安装模型。

增强子进程上限 90 秒，超时或模型缺失回退；运行阶段指定本地模型路径，不自动下载缺失模型。

PDF 各分支统一使用“先融合文本证据，再关联表格”的顺序。只合并同一位置且内容相同的文本框；不同位置的重复结果、单位及符号均保留，内容冲突或缺少坐标时不静默删除。纯文本 PDF 保留文本层，混合 PDF 合并后只做一次表格增强，标记随最终文本框保存。

候选识别使用表头定义的名称和本次结果列，不依赖缩写列的位置；无结果的单元格不从参考列补值。文字框稍被截断时，额外要求中心唯一归属、至少 60% 覆盖且比次优单元格高至少 20 个百分点；不能仅按最近距离匹配。

## 完整性验收

- 从原始 PDF 文本框、worker 输出、表格单元格、候选行到 AI 输入逐层核对；同文本不同位置不得消失。
- 使用 `recognize_input` 实际入口、默认渲染参数，并覆盖 `pdf_text` 和 `pdf_text_plus_render` 两条路径，不能只调用结构模型替代端到端验收。
- 本轮在隔离副本验证两页报告：38 行表格完整恢复，30 行非空结果均成为候选且进入 AI 输入；8 行原件无结果保持空白。未调用外部 AI，未覆盖正式报告。
- AI 输入完整不等于所有项目进入趋势；数值类型、单位口径、标本和人工治理规则仍需后续验证。

`OCR_TABLE_ENHANCEMENT=off` 关闭增强；默认 `auto`，环境可用时启用。模型增强不替代标本消歧、单位兼容性和趋势准入判断。
