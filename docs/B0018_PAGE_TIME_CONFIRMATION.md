# B0018 同页指标时间确认

## 原因和范围

原来的 ObservationTimeEditor 固定只提交当前 observationIds，虽然底层已有多指标检查归属能力，时间编辑入口没有提供同页应用选择。工单来自 fnOS 0.2.19、Windows Edge，只附应用界面截图，无报告原件。没有将界面截图作为报告导入，也没有调用 OCR 或 AI。

本轮归入 0.3.4，后续已按用户明确要求将项目版本号更新为 0.3.4，新增说明记在 `0.3.4 - Unreleased`。0.3.3 已正式发布，其 changelog 区块标为已发布；本轮未提交、推送、创建 tag 或发布。

## 最小实现

- 延用原时间编辑入口、日期控件、按钮和主题样式。当前指标存在明确的单页来源，且该页另有可处理的时间待核对指标时，默认勾选「同时确认第 N 页其余 X 项待核对时间」，保存按钮显示总数量。取消勾选即为单项保存。
- GET examinations 返回可确认的 pageTimeGroups；候选由服务端以观察项的原始页码和可选 pageId 核实。跨页证据、来源缺失或页码与页 ID 不一致时不纳入，不能使用检查记录中可能跨页的日期证据推断本页。
- PUT examinations 可选择 applyToPage=true，客户端仅传当前项，服务端按最新状态重算范围。仅纳入 confirmationStatus=pending、没有 occurredAt 且时间归属非人工确认的项目；其他页、明确时间和人工归属均保留。
- 按原检查记录分别保存日期，不将不同标本、机构、方法、报告编号等信息合并。原检查记录保持不动，为本页选中项建立人工确认归属，跨页共用旧检查记录的项目不受影响。数值、单位、参考范围和原始证据不改写。
- 复用现有保存校验与事务、成员权限、报告和检查双版本、幂等请求及审计。整页处理有一步失败即回滚，不新增接口、数据表或通用批量操作框架。

- UI 定向 8 项通过，包括默认同页选择、数量和按钮文案、取消勾选后的单项提交，以及既有日期/时刻、HTTP 请求标识和只读行为。
