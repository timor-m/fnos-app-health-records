# 骨密度分部位记录

0.3.4 未发布改动。沿用报告、指标 observation、检查归属和趋势快照，不新增骨密度业务表。

## 录入与展示

报告详情 → 指标总览 → 查看全部 → 骨密度。选择部位，可添加多个部位；每个部位至少填写 BMD、T 值、Z 值中的一项。股骨要求明确左右侧。BMD 使用 g/cm²，T/Z 无单位；缺失项不填零。已有项目仍通过编辑指标修改，日期沿用现有时间核对入口。

趋势按方法、部位（包含腰椎组合）、左右侧和测量项区分。同部位使用 BMD/T/Z 按钮切换，默认优先展示 BMD；只显示当前筛选下有数据的项目，只有一项时隐藏切换按钮；不同单位不共用纵轴。数量按实际展示的部位卡片统计，BMD/T/Z 不重复计数；数据点数量保持原始记录总数。切换不改变卡片位置；分页以部位卡片为单位，每页附带卡片内匹配的测量项摘要，图表与历史仍按需读取；翻页不重复展示已出现的部位。关注也以同部位卡片为单位，兼容已有单项关注，从任一页签取消关注均生效，其他账号和普通指标的单位区分保持独立。分组下拉展示当前搜索和状态条件下的匹配数。设备与交叉校准条件未确认时不自动判断 DXA 数值变化。

## 数据兼容

- observations 增加可空 measurement_site、measurement_laterality；method 沿用既有字段。
- 旧数据不批量猜测部位或左右侧。明确 DXA 而缺少部位的记录保留待核对，不能借机构内趋势绕过核对；已有 QUS 保持原含义。
- BMD、T、Z 使用三个核心定义，部位作为数据维度，避免为每个组合建立指标。趋势键附带部位与左右侧，标准字典键不变；分组展开这些趋势键。
- 旧客户端更新未传新增字段时保留已有值。人工补充/校对、重跑覆盖保护、删除来源标记及检查归属均携带部位身份。
- 使用现有启动补齐机制：缺字段前备份，事务补齐，失败回滚并阻止启动，重复启动不覆盖数据。不新增编号迁移，也不改已发布迁移。

## 提取边界

本地 DXA 表格路径要求明确方法、表头、部位列、数值列、可确认的测量日期以及汇总 BMD 与历史表当前值一致。根据坐标配对，隔离曲线刻度、年龄、变化量；支持表格中有明确依据的月/日/年格式。非唯一配对、未知部位、低置信数值、无可靠日期、混合文档或有明确叙事结论时保留既有 AI 提取路径；没有放宽普通表格的安全判断，也没有增加 AI 重试。

持久化时重新根据当前原始 OCR 验证 DXA 数值和部位，不信任模型自行声明的来源标签；检查日期同样回指这份经过验证的表格。其他布局仍可能需要人工核对，原件始终保留。

## 验证

使用合成数据覆盖：不同部位/左右侧不冲突、零与缺失值、历史日期、布局和日期歧义、来源校验、普通指标、两页完整落库、多部位原子保存与版本冲突、旧客户端编辑、人工覆盖、旧库备份/补齐/失败回滚及分页摘要。UI 测试覆盖录入、错误保留、切换位置/单位、筛选计数和跨页签关注操作防重复。混合普通指标回归保留原有单位区分；分页、关注和筛选不改写来源测量。

股骨左右侧专项回归覆盖股骨颈、颈上部、颈下部、Wards 三角、大粗隆、股骨干和股骨全部。合成左右两页同日检查分别使用相同和不同数值，逐项核对 42 条 BMD/T/Z 趋势、44 个测量点及 14 张部位卡片，并检查来源页、历史日期、分组分页、跨页签关注及取消关注。UI 切换左侧 T 值或右侧 Z 值不改变另一侧的选择；缺侧别、矛盾侧别及同页双表不走单表快捷提取。分别去掉趋势标识、卡片分组中的侧别后，新增回归能检出误合并，检查后恢复。该项未发现新的产品逻辑缺陷，仅补充回归与说明；右侧仍是合成样例验证，不能代表所有机构布局。

真实原件、OCR 与逐项核对结果仅保存于本地忽略目录 `.data/qa/bone-density`，不纳入仓库。原件重跑经正常上传、OCR、提取、持久化、检查归属和趋势链路；不通过手改指标或日期验证效果。

消融检查分别去除部位趋势身份和严格表格路径，相关合成回归均能检出错误，随后恢复。补充检查中再分别移除整部位关注、按卡片分页和匹配数展示，新增回归均能检出遗漏，检查后已恢复。保留两列可空元数据与 BMD/T/Z 三个指标定义，独立长度项沿用普通指标结构，不增加设备模型、独立测量表或通用动态表单框架。


## 左右侧髋关节中轴长度

这是独立的长度测量，不属于 BMD/T/Z 页签：使用独立核心定义 `hip_axis_length_left` / `hip_axis_length_right`，标准名分别为“左侧髋关节中轴长度”与“右侧髋关节中轴长度”，功能检查分类、定量类型、默认单位 mm。可信别名仅包含明确左右侧的中文写法及 Left/Right Hip Axis Length；不加入无侧别的 HAL、髋轴长度等泛称，模型预整理名称不能推断缺失侧别或颠倒来源侧别。核心字典 revision 递增为 23，兼容本地已安装的 21、22 号不可变快照，不删除旧快照；未发布远程字典。

原报告的“髋关节中轴长度比较（mm）”提供提取上下文，但只有明确 `左=实测值mm` / `右=实测值mm` 的来源能建立对应侧测量；同页或同一行的两个明确侧别分别建立记录，每侧最多一个值，数值相同也不合并；参考均值、图上的差值和坐标刻度均不建立个人指标，不作为参考上下限。检查日期回指同页已验证的本次检查日期，不向历史年份补造长度。来源缺失、多候选、错误侧别、非正值或低置信度时保留正常核对路径，不猜值。

依据：[GE HealthCare 的 DXA 临床应用资料](https://www.gehealthcare.com/content/dam/gehc/sitecore-migrated-assets/gehc/us/files/products/bone-and-metabolic-health/trabecular-bone-score/v18-clinical-applications-sheet_jb16655xx.pdf)将 Hip Axis Length 作为测量项列出；[Hologic HL7 接口定义](https://www.hologic.com/sites/default/files/2018-05/HL7%20Results%20Interface%20%28MAN-03662%29%20English%20Rev%20002%2004-17.pdf)将 HSA HIP AXIS LENGTH 定义为数值、单位 mm。它们支持独立长度指标的口径，不据此套用参考范围或推断个体结论。

新增合成回归覆盖左侧、右侧及同页双侧、相同数值不合并、单侧重复或矛盾标签、长度与均值/差值区分、左右侧边界、独立趋势及关注隔离、原件来源与日期归属；原有 BMD/T/Z 全部值、部位与日期仍须逐项保持一致。编辑长度时保持普通指标表单，避免出现 BMD/T/Z 的部位选择框。

HAL 消融分别移除独立长度提取、左右侧匹配边界和独立编辑表单判断，对应回归均能检出错误，检查后已恢复。本次补齐右侧后，再分别禁用右侧提取、移除侧别匹配保护，右侧及双侧入库回归均能检出错误，恢复后通过。左右侧复用现有指标、趋势和关注结构，不增加新表或额外 AI 重试。

右侧和双侧使用合成 OCR 样例验证；当前真实原件仅包含左侧，不把合成验证表述为右侧原件实测。
