新增专项覆盖：

- 一个成员的全部报告共享；其他成员不暴露；管理员无默认访问/编辑/共享权。
- viewer 不能管理，manager 默认不能转授权；版本过期拒绝；最后共享管理者不能降级、停用或强制删除。
- 新本地账号无自动本人；显式创建本人幂等；跳过保存；共享的 self 不显示为接收者本人；隐藏互不影响。
- 迁移唯一候选/多候选、历史委托 manager 不自动补共享能力、重复迁移不覆盖后续选择。
- 同实例恢复保留普通账号凭据、viewer 授权、本人和隐藏偏好，清除会话；上传备份同样走预检。
- 跨实例同 ID、不同 NAS 相同 UID 隔离；受控映射预览和执行不重写创建者。
- 恢复身份处理故障保护当前数据；预检身份变化后拒绝旧计划；历史修复实际执行与撤销，保留安全快照和管理者；孤立档案显式应急认领仅在核实、预览确认后执行。
- HTTP 原件访问 no-store、跨报告页面 ID 拒绝、撤权后旧 URL 拒绝、viewer 上传拒绝。
- 前端全部隐藏时不发送无成员提醒查询、过期异步成员列表不能覆盖新授权列表、切换账号立即清空旧状态。

部分旧测试原先要求“自动本人”“管理员接管全部成员”“其他账号统一停用”，已改为新权限规则；其他上传、OCR/AI、报告、数据库故障恢复等原有回归保留。构建仍有既有的大 chunk 提示，Node SQLite 有 experimental 提示，均非失败。

## 消融复查

沿用原成员授权表、SQLite 事务、备份校验和存储请求/后台任务忙状态；未引入外部服务、邀请系统或独立 ACL 框架。保留必要的新增偏好/待映射小表；移除登录自动建档、管理员绕过、恢复全量授权及停用、前端强制删除绕过提示，避免两套矛盾路径。跨实例人工映射采用受控命令行工具，没有增加独立管理后台。
