## 实施范围

- 统一纯证据评估器、真实 OCR/AI 快照构建；复用 OCR 行重建和指标字典。删除旧医疗编号直通、文本前缀、相似度和宽松指标重合规则。
- 处理队列采用独立暂停动作，绑定双方证据版本，要求目标已有当前可用结果；补页和普通 AI 完成后执行非阻断后置核验。
- 新增当前运行状态未编号草案，旧库先备份后补齐；保留人工决定与历史，原件变化后的 duplicate 明示需要复核。
- 新增继续、按报告对排除并继续、历史恢复及后置重检接口。继续与人工决定处于同一短事务，重试复用任务，失败回滚。只读与跨成员权限在服务端约束。
- 详情与设置沿用现有组件和按钮，区分暂停、完成后提示、内容版本变化、失效与核验失败；对比展示原始证据、可靠差异、局部不确定及完整性风险。
- `CHANGELOG.md`、架构和迁移文档已更新。规则参数与兼容策略见 [规则说明](./REPORT_DUPLICATE_DETECTION.md)。
