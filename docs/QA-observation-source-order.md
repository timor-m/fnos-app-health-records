# 原文顺序与按页补录验收

第一轮提供“分类查看 / 原文顺序”和按页补录；第二轮补齐人工框选定位。

- 报告详情 → 查看全部 → 点击“原文顺序”，可通过并排按钮切换回“分类查看”。每个报告页均有分组，通过右上角唯一的“补充指标”入口补录，空页同样支持。补充指标打开独立居中大弹窗，移除补充副标题及重复说明，框选、缩放、清除与旋转合并为紧凑工具栏，旋转不再单独占行；图片默认按可用宽高完整适配，旋转及窗口大小变化时重新适配，手动放大后允许滚动；桌面优先扩大左侧原图，右侧表单宽度为 320px，表单内容独立滚动并与滚动条留有间距，取消及保存按钮固定在右侧底部，展开更多信息不改变弹窗高度，左侧原图不被底部通栏按钮压缩，触屏纵向展示；编辑已有指标仍在原编辑列，仅保留原表单，不显示来源选页和框选工具。各类指标共同展示，保留趋势资格、待核对及人工标记。
- 通过现有指标证据关联 OCR 行，使用 OCR 阅读方向中的位置排列；先按页，再按独立栏区及行序排列。查看时旋转和缩放不改变阅读顺序。复杂布局不保证完全还原，应结合原件核对。
- 有来源页但无可靠坐标、坐标失效或位置加载失败的指标放在该页末尾并标记“位置待确认”。无有效来源页的单独展示，不伪造位置。跨页指标沿用现有主来源页定位，列表不因多条证据重复生成指标。
- “补充指标”默认选中当前查看的来源报告页，也可在补录表单选择其他来源页或“来源页待确认”；保存复用现有补录接口的可选 sourcePageId，服务端核对归属、权限和报告并发版本。选页只记录来源，不代表自动验证指标内容。
- 来源通过页面 ID 关联；页码调序后展示当前页码，重新解析通过人工覆盖记录恢复关联，来源页删除后不能误指向同页码的其他页面。
- 历史数据无需重新调用 AI；第一轮按需读取已有 OCR，不增加 AI token。未增加数据库结构或迁移，schema 保持 v19。

## 检查

1. 合成双栏数据：乱序指标应按左栏从上到下、右栏从上到下排列；全宽章节及不同页分组保持稳定，重复名称不合并。
2. 分类模式保持原有分组及编辑、删除能力，原文模式显示各类状态。
3. 切换到空白来源页 → 补充指标 → 填写 → 保存：请求携带对应页面 ID，点击补录项打开该页，无 OCR 行时不伪造高亮。
4. 页面调序、删除、重新解析及刷新后检查实际保存关联；跨报告页和过期并发版本必须拒绝。
5. 图片 / PDF 旋转、不同显示尺寸时原有 OCR 高亮继续正确；坐标过期时保守提示位置待确认。
6. 消融检查：分别移除栏区排序、稳定页面 ID 和人工覆盖来源，验证对应回归能发现排序或来源错误；不新增排序持久化表及 AI 重跑。

自动化：`observation-source-order.test.ts`、`report-detail-review.test.ts`、`observation-source-page.test.ts`，并回归现有页面方向、OCR 高亮和人工编辑测试。

## 人工框选来源区域

- 补录或编辑指标，选择来源页，在表单内原图点击“开始框选”，拖出矩形后自动退出框选；退出时可滚动查看放大后的原图。可先放大或旋转再框选；“清除定位”仅清除区域，保留来源页。
- 框选区域以 0～1 的比例坐标存入既有证据 JSON 和人工覆盖记录，记录坐标方向及服务端读取的原件指纹。现有补录、编辑接口新增可选 sourceRegion，无结构变化，schema 保持 v19。
- 显示时按当前图片 / PDF 坐标方向换算，区域与原图一起缩放旋转。原文顺序使用 OCR 阅读坐标，人工框选指标与自动识别指标共同排列。
- 框选不触发 OCR 或 AI，不把人工区域冒充 OCR 行证据。编辑其他字段不覆盖已存定位；改页会清除旧框，来源页删除或原件指纹不匹配时不显示旧框。
- 验收需覆盖触屏指针取消、不同缩放及四个方向的逆变换、保存后刷新、编辑 / 清除、重新解析后保留、跨报告页和越界框拒绝、PDF 方向变化、原件指纹变化。
