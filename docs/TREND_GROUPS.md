# 趋势分组筛选

在趋势列表原有“指标分组”入口中，展开检查领域，点击需要的项目组合。采用单选，选中后自动关闭，入口显示当前分组名称。触屏复用原有底部抽屉，桌面复用原有下拉面板。

- 点击领域名称仅展开或收起；点击领域内的“全部”查看整个领域，点击“甲功五项”等选项查看对应组合。
- 搜索支持分组名、指标名和已有别名；选中项高亮并显示勾号，选择“全部指标”取消分组限制。不同单位的现有序列仍保留。
- 数字表示“当前成员可查看的趋势指标数 / 已配置指标数”，不表示报告数量。默认隐藏没有数据的项目；开启“显示全部项目”后可查看，但不可选择空项目。
- 切换成员会重新加载分组及计数，清除原成员的分组选择。未归类指标仍显示在“未分组指标”；领域内尚未细分的指标放在“其他指标”。
- 不修改现有图表、视力表示法、标准化或趋势准入条件，不补零或推测缺失项目，不重新执行 OCR / AI。

## 数据及接口

复用现有 `indicator_catalog` 的主键和 `canonical_key`。`indicator_groups` 是单父级树；`indicator_group_members` 是多对多关联。同一指标可属于多个组合，不改变原有 `category_key` 和历史数据。

配置位于 `dictionary/groups/builtin.json`，只使用明确的标准指标 key 或分类 key。一级领域复用当前生效 taxonomy 的稳定 key（如 `general`、`laboratory`），不另建重名领域。屈光度等尚无明确字典项目的分组不空造。

应用启动初始化内置分组；读取分组时根据当前生效目录重新核对，支持远程字典安装和回滚。仅目录变化时刷新内置关联，保留 `source=user` 的分组和关系。

## 我的分组

趋势页“指标分组 → 管理我的分组”支持新建、编辑和删除个人组合，也可复制内置组合后增减指标。暂无趋势数据时，空状态仍提供管理入口。名称为 1–40 字，选择 1–200 个标准指标；搜索支持标准名称、字典别名和分类。内置组合不可直接修改，删除个人组合不会删除报告或指标。

分组归当前账号所有，不对其他账号（包括管理员）开放管理；可跨当前账号有权访问的成员复用，成员数据继续按原权限校验。选择尚无数据的指标不会补零，筛选显示“已有数据数 / 配置数”；不同单位仍保留独立序列。当前字典不可用的已选项目保留并标示，允许移除，但不能新选。更新字典不会覆盖个人分组。

管理弹窗复用一个列表/编辑流程，指标列表独立滚动、保存操作保持在底部。保存后立即刷新现有筛选，不修改标准化、OCR/AI 或趋势快照；删除当前筛选分组后回到全部指标。首版不提供共享、多级个人目录或拖拽排序。

- `GET /api/trends/groups?memberId=...` 返回树、当前成员指标 key、实际数和配置数；先按现有成员权限校验，管理员也不能绕过成员授权。
- 页面只传一个 `groupKeys[]`，例如 `GET /api/trends?memberId=...&groupKeys[]=thyroid_5`。后端保留多对多归组及数组参数兼容能力，不在界面提供多选；无筛选参数时保持原有接口行为。未知 key 匹配不到数据，不回退为全选。
- `GET /api/trends/groups/manage` 返回当前账号的个人分组、可复制的内置组合和标准指标目录，不包含成员健康数据；`POST /api/trends/groups`、`PUT /api/trends/groups/:key`、`DELETE /api/trends/groups/:key` 仅操作当前账号的个人分组。名称及指标关联在同一事务保存，输入无效或权限不符时不改动旧组合。
- 分组、目录及关联批量读取，计数来自已通过原有趋势判断的数据，不逐组扫描报告。
- 自定义管理复用已有分组表、所有者字段及关联，不新增结构或迁移；本轮 schema 保持 v19。现有旧库补表和补表前备份机制不变。
