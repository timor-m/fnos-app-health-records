# 概览分类图片图标

概览页的六类统计入口使用用户选定的第一版轻立体插画，素材由内置 imagegen 从设计稿逐枚整理为透明背景，再导出为 160 × 160 PNG。概览 PC 显示 40px，触屏显示 26px；其他位置按空间使用 18–34px；文字名称和计数由页面渲染，图片不包含文字或装饰背景框。

| 文件 | 类型 | 主体 |
| --- | --- | --- |
| report.png | 报告 | 薄荷绿报告夹与蓝色确认标记 |
| imaging.png | 影像 | 深蓝色胸部影像胶片 |
| symptom.png | 症状 | 薄荷绿人体与珊瑚色不适标记 |
| medication.png | 用药 | 绿白胶囊与淡紫药片 |
| vaccination.png | 接种 | 疫苗瓶与薄荷绿注射器 |
| monitoring.png | 监测 / 记录测量 | 乳白电子血压计、青绿袖带与薄荷绿体重秤 |

生成提示词共同约束：从已选定的第一版设计稿提取指定主体，保留原造型、配色、比例、柔和立体光影；只输出单个主体，正方形画布并保留均衡留白，使用真实 alpha 透明底；移除设计稿文字、其他图标和底部预览，不添加圆角背景框、光晕或场景。不使用后续平面版本。

这组图片由 `HealthCategoryIcon.vue` 统一渲染，用于概览、记录分类筛选、记录卡片、详情标题、新增菜单，以及症状跟踪、用药汇总和关联报告等类型标识。图片不再额外叠加背景框；与文字一起出现时作为装饰图片，单独表达类别时提供替代文字。搜索、返回、编辑、上传和 PDF 文件等功能图标继续沿用矢量图标。


## 监测图标

使用内置 imagegen，以现有 report、medication、symptom 三张图作为风格参考生成独立主体；居中裁去多余透明留白，等比导出为 160 × 160 RGBA PNG。沿用 `monitoring.png` 和既有类别图片映射，“记录测量”菜单及监测分类共用，不增加组件、背景框或另一套图标映射。

生成提示词：

> 生成一个用于健康档案 App「记录测量」入口的独立图标。所附三张图片仅作为风格参考，不是修改目标。严格匹配它们的轻立体、圆润实体造型、薄荷绿和青绿色主色、乳白辅助色、柔和高光及细腻材质。主体为一台简洁的乳白色家用电子血压计，带薄荷绿显示屏和圆润青绿袖带，搭配后方略露出的薄荷绿体重秤，组成紧凑清晰的单组主体。显示屏只用简单图形，不出现文字、字母或数字。适度俯视，主体在正方形画布中居中，占比及均衡留白与参考图一致，缩小至26–40px仍能识别。输出真正 alpha 透明背景，不要背景卡片、底座、地面、外部投影、光晕、装饰或场景，不要人物。最终只输出这一个图标。
