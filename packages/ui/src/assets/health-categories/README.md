# 概览分类图片图标

概览页的五类统计入口使用用户选定的第一版轻立体插画，素材由内置 imagegen 从设计稿逐枚整理为透明背景，再导出为 160 × 160 PNG。概览 PC 显示 40px，触屏显示 26px；其他位置按空间使用 18–34px；文字名称和计数由页面渲染，图片不包含文字或装饰背景框。

| 文件 | 类型 | 主体 |
| --- | --- | --- |
| report.png | 报告 | 薄荷绿报告夹与蓝色确认标记 |
| imaging.png | 影像 | 深蓝色胸部影像胶片 |
| symptom.png | 症状 | 薄荷绿人体与珊瑚色不适标记 |
| medication.png | 用药 | 绿白胶囊与淡紫药片 |
| vaccination.png | 接种 | 疫苗瓶与薄荷绿注射器 |

生成提示词共同约束：从已选定的第一版设计稿提取指定主体，保留原造型、配色、比例、柔和立体光影；只输出单个主体，正方形画布并保留均衡留白，使用真实 alpha 透明底；移除设计稿文字、其他图标和底部预览，不添加圆角背景框、光晕或场景。不使用后续平面版本。

这组图片由 `HealthCategoryIcon.vue` 统一渲染，用于概览、记录分类筛选、记录卡片、详情标题、新增菜单，以及症状跟踪、用药汇总和关联报告等类型标识。图片不再额外叠加背景框；与文字一起出现时作为装饰图片，单独表达类别时提供替代文字。搜索、返回、编辑、上传和 PDF 文件等功能图标继续沿用矢量图标。
